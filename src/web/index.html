系统功能说明

本系统围绕"烹饪领域"构建知识图谱（菜谱/食材/调料/工序/口味/功效/人群七类实体，含包含、属于、搭配、相克、适用、具有功效、采用工序、替代八类关系）， 并在此基础上实现：

  • 图谱增强RAG问答：向量文本召回 + 图谱结构化召回两路融合，回答菜谱与食疗问题；
  • 食材替代推理：基于属性相似度与显式替代关系，推荐可替代食材；
  • 饮食禁忌校验：基于规则遍历食材，匹配过敏源/体质/相克，给出风险与调整建议；
  • 可视化与后台：力导向图谱交互浏览，菜谱数据增删改查。
